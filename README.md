# LambdaMC

마인크래프트 서버(Fabric, 1.20.1)에 **람다(Lambda, λ / RBL)** 화폐와 상점 시스템을 추가하는 모드입니다.

## 기능

- **람다(λ) 화폐**: 서버에 처음 접속하면 2,000 λ가 자동으로 지급됩니다. 잔액은 월드 데이터(오버월드 PersistentState)에 저장되어 오프라인에도 유지됩니다.
- **인벤토리 잔액 표시**: 서바이벌 인벤토리 화면(E)에서 레시피북 버튼 옆에 현재 λ 잔액이 표시됩니다.
- **명령어**
  - `/lambdamc shop` — 등록된 상점 목록을 채팅으로 보여주고, 클릭하면 바로 입장합니다.
  - `/lambdamc shop <상점이름>` — 해당 상점 GUI를 엽니다.
  - `/lambdamc rank` — λ 보유량 기준 상위 10명 리더보드를 보여줍니다.
- **기본 상점 `lambdasharp`**
  - 교환(판매): 다이아몬드 → 100λ, 고대 파편 → 500λ, 네더라이트 주괴 → 2,000λ, 드래곤 알 → 10,000λ (서버 전체 단 1회 한정)
  - 고정 판매: 에드(EdShin09)의 머리 (0λ, 설치 불가), 서버 초기화 카드 (100,000,000λ, 서버 전체 단 1회 한정)
  - 일일 로테이션(현실 시간 자정 기준 자동 갱신, 확률: 노말 60% / 에픽 30% / 미스틱 10%)
    - 노말: 기본 무기·도구, 약한 마법 부여 책, 다이아몬드·네더라이트를 제외한 금속류
    - 에픽: 강화된 무기·도구
    - 미스틱: 강력한 마법 부여 책

### "서버 초기화 카드"에 대한 설계 노트

요청하신 "서버 전체 초기화" 카드는 실제로 월드 데이터를 삭제하거나 되돌릴 수 없는 파괴적인 동작으로 구현하지 **않았습니다**. 대신 서버 전체에 경고성 메시지와 사운드를 보내고 "장난입니다" 라는 반전을 주는 **트롤 아이템**으로 구현했습니다 (`ResetCardItem`). 실제 서버/월드를 초기화하는 기능은 되돌릴 수 없는 파괴적 작업이라 모드 차원에서 안전하게 구현하기 어렵고 위험하므로 이 방식을 선택했습니다. 다른 동작을 원하시면 말씀해 주세요.

## 빌드 방법

```bash
./gradlew build
```

빌드된 모드는 `build/libs/lambdamc-1.0.0.jar` 에 생성됩니다. 이 jar를 서버(및 접속하는 클라이언트 - 인벤토리 UI/상점 화면 렌더링을 위해 클라이언트에도 설치 필요)의 `mods` 폴더에 넣고, [Fabric API](https://modrinth.com/mod/fabric-api)가 함께 설치되어 있어야 합니다.

> 이 저장소를 생성한 샌드박스 환경은 Fabric/Mojang 메이븐 저장소에 대한 외부 네트워크 접근이 차단되어 있어 `./gradlew build`를 직접 실행해 컴파일 검증을 하지 못했습니다. 로컬 환경(인터넷 접근 가능)에서 빌드 시 오류가 발생하면 알려주시면 수정하겠습니다.

## 요구 사항

- Minecraft 1.20.1
- Fabric Loader ≥ 0.15.0
- Fabric API
- Java 17+

## 프로젝트 구조

- `src/main/java` — 서버/공통 로직 (경제, 상점 데이터, 명령어, 스크린핸들러)
- `src/client/java` — 클라이언트 전용 로직 (상점 화면 렌더링, 인벤토리 잔액 HUD)
- `src/main/resources` — `fabric.mod.json`, 언어 파일, 아이템 모델
