# LambdaMC

마인크래프트 서버(Fabric, 1.20.1)에 **람다(Lambda, λ / RBL)** 화폐, 기본 상점, 플레이어 커스텀 상점 시스템을 추가하는 모드입니다.

## 기능

- **람다(λ) 화폐**: 서버에 처음 접속하면 2,000 λ가 자동으로 지급됩니다. 잔액은 월드 데이터(오버월드 PersistentState)에 저장되어 오프라인에도 유지됩니다.
- **상시 HUD**: 플레이 화면 우측 상단에 항상 현재 λ 잔액이 표시됩니다.
- **`M` 키**: 상점 목록 메뉴를 엽니다. 검색/정렬(최신순·인기순·이름순), 내 상점만 보기, 상점 만들기, 기본 상점 바로가기를 제공합니다.
- **명령어** (M 키 메뉴는 내부적으로 이 명령어들을 호출합니다 — 콘솔/채팅에서 직접 써도 됩니다)
  - `/lambdamc shop [list [정렬] [검색어]]` — 상점 목록
  - `/lambdamc shop open <이름>` — 상점 입장(구매/판매)
  - `/lambdamc shop create <sell|buy> <이름>` — 내 상점 만들기
  - `/lambdamc shop manage <이름>` — 내 상점 관리(상품 목록, 클릭 시 삭제)
  - `/lambdamc shop addproduct <이름> <가격>` — 손에 든 아이템을 상품으로 등록(판매 상점은 실제로 재고에 입고됨)
  - `/lambdamc shop removeproduct <이름> <번호>` — 상품 삭제
  - `/lambdamc shop delete <이름>` — 상점 삭제(재고 반환)
  - `/lambdamc shop warehouse <이름>` — 상점 창고(바닐라 상자형 GUI) 열기
  - `/lambdamc rank` — λ 보유량 상위 10명 리더보드
  - `/lambdamc admin give|set <플레이어> <금액>` — 잔액 지급/설정 (op 권한 필요)
  - `/lambdamc admin stats` — 서버 경제 통계 (op 권한 필요)
  - `/lambdamc admin deleteshop <이름>` — 상점 강제 삭제 (op 권한 필요)
  - `/lambdamc admin log [개수]` — 최근 거래 로그 (op 권한 필요)

### 기본 상점 `lambdasharp`

- 교환(판매): 다이아몬드 → 100λ, 고대 파편 → 500λ, 네더라이트 주괴 → 2,000λ, 드래곤 알 → 10,000λ (서버 전체 단 1회 한정)
- 고정 판매: 에드(EdShin09)의 머리 (0λ, 설치 불가), 서버 초기화 카드 (100,000,000λ, 서버 전체 단 1회 한정, 트롤 아이템)
- 일일 로테이션(현실 시간 자정 기준 자동 갱신, 기본 확률: 노말 60% / 에픽 30% / 미스틱 10%)
  - 노말: 기본 무기·도구, 약한 마법 부여 책, 다이아몬드·네더라이트를 제외한 금속류
  - 에픽: 강화된 무기·도구
  - 미스틱: 강력한 마법 부여 책

가격/확률/시작 자금/수수료/가격 제한 등은 `config/lambdamc/config.json` (서버 첫 실행 시 자동 생성)에서 재컴파일 없이 조정할 수 있습니다. 단, 일일 로테이션에 어떤 구체적인 아이템들이 포함되는지(예: 어떤 마법 부여 책들인지)는 코드(`shop/ShopItems.java`)에 있고, config로는 확률 가중치·가격 몇 개만 조정됩니다.

### 커스텀(플레이어) 상점

- 플레이어는 **판매 상점 1개 + 구매 상점 1개**까지 만들 수 있습니다 (config로 조정 가능).
- **판매 상점**: 상품 등록 시 손에 든 아이템 전체가 상점 창고로 들어가고, 다른 플레이어가 구매하면 창고 재고가 실제로 줄어듭니다(품절 시 "품절"로 표시).
- **구매 상점**: 등록은 아이템을 소모하지 않고 "얼마에 살지"만 기록합니다. 다른 플레이어가 팔면 상점 주인의 λ 잔액에서 즉시 차감되어 판매자에게 지급되고, 아이템은 상점 창고에 쌓입니다 — 주인은 `warehouse` 명령/버튼으로 직접 수거해야 합니다.
- 모든 커스텀 상점 거래에는 **수수료**(기본 5%, config `customShopFeeRate`)가 서버(사실상 소각)로 빠집니다.
- 상품 가격에는 상한/하한(config `minListingPrice`/`maxListingPrice`)이 있습니다.
- 상점 주인이 오프라인일 때 판매/매입이 발생하면 접속 시 채팅으로 알림을 받습니다.
- 관리자는 `/lambdamc admin deleteshop`으로 아무 상점이나 강제 삭제할 수 있습니다. 단, 이 경우 주인이 오프라인이면 상점 창고에 남아있던 실제 아이템은 반환할 방법이 없어 소실됩니다(알려진 한계).

### "서버 초기화 카드"에 대한 설계 노트

"서버 전체 초기화" 카드는 실제로 월드 데이터를 삭제/롤백하는 파괴적인 동작으로 구현하지 **않았습니다**. 대신 서버 전체에 경고 메시지와 사운드를 보낸 뒤 "장난입니다"로 반전되는 **트롤 아이템**입니다 (`item/ResetCardItem.java`). 실제 서버 초기화 기능이 필요하면 별도로 말씀해 주세요.

## 빌드 방법

```bash
./gradlew build
```

빌드된 모드는 `build/libs/lambdamc-1.0.0.jar` 에 생성됩니다. 서버와, 접속하는 모든 클라이언트에 동일한 jar를 설치해야 하며(HUD/M키 메뉴/상점 GUI가 클라이언트 렌더링이라 필수), [Fabric API](https://modrinth.com/mod/fabric-api)가 함께 설치되어 있어야 합니다.

> 이 저장소를 생성한 샌드박스 환경은 Fabric/Mojang 메이븐 저장소에 대한 외부 네트워크 접근이 차단되어 있어 `./gradlew build`를 직접 실행해 컴파일 검증을 하지 못했습니다. 코드는 1.20.1 Fabric API 기준으로 꼼꼼히 리뷰했지만, 로컬(인터넷 되는) 환경에서 빌드 시 오류가 나면 알려주시면 바로 고치겠습니다.

## 요구 사항

- Minecraft 1.20.1
- Fabric Loader ≥ 0.15.0
- Fabric API
- Java 17+

## 알려진 단순화/한계

- 상점 이름에 공백이나 한글이 들어가면 명령어에서 항상 큰따옴표로 감싸야 합니다 (M키 메뉴는 자동으로 처리합니다).
- 일일 로테이션 상품 "종류"는 코드에 고정되어 있고, config로는 확률/가격 일부만 조정됩니다.
- 관리자가 오프라인 플레이어의 상점을 강제 삭제하면 창고에 남은 실물 아이템은 반환되지 않고 소실됩니다.
- 커스텀 상점의 "구매" 매입 대금은 상점 주인의 실시간 λ 잔액에서 즉시 차감됩니다(별도 에스크로 없음) — 즉 주인 잔액이 부족하면 그 상품은 일시적으로 매입 불가 상태가 됩니다.

## 프로젝트 구조

- `src/main/java` — 서버/공통 로직 (경제, 설정, 상점 데이터/로직, 명령어, 스크린핸들러)
- `src/client/java` — 클라이언트 전용 로직 (HUD, M키 메뉴, 상점/관리 화면 렌더링)
- `src/main/resources` — `fabric.mod.json`, 언어 파일, 아이템 모델
